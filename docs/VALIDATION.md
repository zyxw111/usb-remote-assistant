已完成：

- 主机端和副机端 Release EXE 构建；两个 Visual Studio 项目也能完成构建。独立脚本不依赖 Visual Studio；IDE 构建建议安装 4.8 Targeting Pack。
- 首次配置和板卡页界面渲染检查；预览不显示机器的实际网口信息。
- 空白默认配置、随机配对密钥、配对文件导入／导出、本地设置隔离、取消设置不改动当前配置。
- EasyTier 自定义网络名、包含 Unicode／引号／反斜线／首尾空格的自定义密码；128 次独立随机密码生成；导入保留本地核心程序路径；旧格式配对拒绝。
- 新网络配置在线同步的真实本机 TCP 往返、加密数据篡改拒绝、错误配对密钥拒绝；确认发送后才运行完成回调。
- 官方 EasyTier 2.6.4 Windows x64 完整包（SHA-256 与官方一致）接受生成的 TOML、Unicode 密码、临时监听端口、回环 RPC、静默日志选项。此检查显式使用无 TUN 模式和回环对端，结束后停止测试进程，不修改已有网络。
- 未选择设备时不自动接入；关闭不释放应用启动前已有的 USB 绑定，只释放本程序取得的绑定。
- 主机先启动、副机后启动、晚插入下载器、断线恢复、缓存状态过期与停止重试。
- SSH 双向 TCP 转发：3 MiB 请求与 2 MiB 响应分别校验 SHA-256，半关闭后仍可接收响应；板卡端口离线后恢复、来源限制、端口占用和活动会话关闭。
- 配对状态查询和板卡设置同步；文件会话占用传输锁时状态查询仍能完成。
- 文件协议完整回归：混合文件、Unicode 路径、空目录、强制断线续传、损坏分块拒收、损坏前缀重传、同名冲突保留、错误密钥拒绝，以及大于 4 GiB 的稀疏逻辑文件完整校验。

这些测试不需要真实第三方 USB 程序，不会编程开发板或修改防火墙。USB 枚举与恢复测试使用模拟接口；网络和文件测试使用本机 TCP。没有用两台异地电脑实测本版 EasyTier 虚拟网卡组网或网络切换，不能据此保证所有下载器、驱动、VPN、FPGA 工具和 Linux 板卡均已实机兼容。

公开包的隐私核对另针对将发布的源码、ZIP 条目及 EXE 内容进行：检查没有旧环境的实际地址、网络 ID、设备序列号、用户路径、计算机名或配对密钥；不包含运行配置、日志、测试数据、Git 历史或第三方可执行文件。


## 可选官方核心配置检查

先运行 `build.ps1 -RunTests`，再用测试 EXE（生产 EXE 不含此入口）执行：

```powershell
& .\.artifacts\tests\UsbRemoteAssistant.Tests.exe --core-smoke-test .\.artifacts\tests\core-smoke-test.txt 'D:\EasyTier\easytier-core.exe'
```

将最后一个路径替换成保留完整 DLL／驱动目录的官方核心位置。测试运行约三秒，报告写入指定路径；无 TUN 模式不创建虚拟网卡。此检查不验证异地链路或实际设备。
